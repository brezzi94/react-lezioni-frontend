# Cani e padroni

Web app React che mostra un elenco di cani con i rispettivi padroni: si possono vedere i dettagli di ogni padrone, cercare un cane per nome e aggiungerne di nuovi.

## Avvio del frontend

```bash
npm install
npm run dev
```

L'app si apre su `http://localhost:5173`. L'indirizzo del backend è nel file `.env` (`VITE_API_BASE_URL`).
